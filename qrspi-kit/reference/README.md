# reference/

Example project `CLAUDE.md` files, paired with the profiles. Not installed by the kit and
not part of the skill — copy from them by hand when setting up a new project, or merge the
relevant sections into a CLAUDE.md that already exists.

| File | Pairs with |
|---|---|
| `claude-md-composable-storefront.md` | `profiles/composable-storefront.json` (Angular Spartacus) |

A project's `CLAUDE.md` is authoritative for its conventions, and QRSPI's stages defer to it.
Keeping a worked example next to the profile means a new project can state its conventions
without inventing the structure from scratch.
