# SAP LLM Template

A minimal SAP Commerce 22.11 starter project with no custom Java code — configuration, project structure, and tooling only. Use this as the cleanest possible foundation when building a new SAP Commerce extension from scratch.

## Claude Code Setup

This project exists to demonstrate a Claude Code setup for a pure SAP Commerce project with no existing implementation. It includes a `CLAUDE.md` with build commands, project rules, and key paths, plus a set of `.claude/skills/` covering SAP Commerce development patterns, ImpEx, FlexibleSearch, and Java best practices. The intent is to show how Claude Code should be configured before any feature code is written — so the AI assistance is in place from the very first line.

## What's Included

- CCv2-compliant project structure (`core-customize/`)
- Empty `llmtemplate` OCC extension scaffold ready for implementation
- `sampledatamcp` extension with sample store data (catalog, customers, orders)
- Local development scripts for server lifecycle and HAC console operations
- Full `CLAUDE.md` and `.claude/skills/` — no code, just configuration
